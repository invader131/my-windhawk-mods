# Windhawk Mods

A collection of my custom Windhawk mods for Windows.

## Mods

| Mod | Description |
|---|---|
| [Battery Charge 98% Notification](./battery-charge-98-notification/) | Shows a notification when the battery reaches 98% while charging. |
| [Bluetooth Lid Toggle](./bluetooth-lid-toggle/) | Automatically handles Bluetooth based on the laptop lid state. |
| [Hide Explorer Taskbar Icon](./hide-explorer-taskbar-icon/) | Hides the Explorer icon from the taskbar. I use FilePilot, so i don't need explorer to show up (the script is used for keeping the splitter from my dock script) |
| [Keep Auto Brightness](./keep-auto-brightness/) | Keeps automatic brightness behavior enabled. |
| [macOS Style Dock](./macos-style-dock/) | Provides a macOS-style dock experience on Windows. |
| [Reaper Hide Menu](./reaper-hide-menu/) | Hides the REAPER menu bar. |
| [REAPER Power Mode](./reaper-power-mode/) | Adjusts power-related behavior while using REAPER. |
| [SoundID Reference No GUI](./soundid-reference-no-gui/) | Prevents the SoundID Reference GUI from appearing while keeping the plugin active. |
| [Top Menubar](./top-menubar/) | Provides a customizable top menu bar experience. |

## Installation

1. Install [Windhawk](https://windhawk.net/).
2. Open the mod you want to use.
3. Copy the contents of its `.wh.cpp` file.
4. Install the mod through Windhawk's custom mod editor.
5. Compile and enable the mod.
